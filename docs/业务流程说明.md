# AI短视频电商提效系统 - 业务流程图说明（补充异常分支与字段级数据流）

## 主流程

选品 -> 内容拆解 -> 秒级脚本 -> 视频制作 -> 发布/投流 -> 客服私域 -> 数据复盘 -> 知识库沉淀

## 节点明细（含输入/输出/责任人/状态/异常）

### 1. 选品板块
- 输入：市场数据、商品信息
- 处理：评分筛选（同款>=5家、视频成交占比>50%、转化率>=15%、小体积易运输）
- 输出：products 表（id/name/category/price/heat_score/target_audience/selling_points/status）
- 责任人：选品专员（张三）
- 状态：待评估 -> 已入库 -> 在售 -> 淘汰
- 异常分支：商品为品牌独家/医疗功效/大型设备 -> 直接淘汰，不进入内容环节
- 字段级数据去向：product.id 作为后续 contents.product_id 的外键

### 2. 内容拆解板块
- 输入：products 表
- 处理：拆解爆款 -> 提炼钩子/结构 -> 设计二创方向
- 输出：contents 表（id/hook/target_audience/structure/conversion_point/product_id）
- 责任人：内容策划（李四）
- 状态：待拆解 -> 拆解中 -> 已完成
- 异常分支：对标视频无法拆解（无完整结构）-> 标记"结构缺失"，转人工
- 数据去向：content.id 关联到 scripts.content_id

### 3. 脚本分镜板块
- 输入：contents 表 + 商品卖点
- 处理：AI工作流生成30秒脚本 + 秒级分镜 + 质检清单（人工审核节点）
- 输出：scripts 表（id/shot_table/review_status/product_id/content_id）
- 责任人：内容策划/剪辑协同
- 状态：草稿 -> 已审核 -> 已定稿
- 异常分支：AI输出缺少分镜/提示词/剪辑要点 -> 重新生成（自动重试2次）
- 数据去向：script.id 关联到 videos.script_id

### 4. 视频制作板块
- 输入：scripts 表
- 处理：AI生成画面 -> 素材筛选 -> 剪映精剪 -> 成片质检
- 输出：videos 表（id/title/script_id/qa_status/platform/status）
- 责任人：剪辑师（王五）
- 状态：制作中 -> 质检中 -> 已发布
- 异常分支：质检不通过（出现价格/明星/logo/极限词/水印）-> 打回重新剪辑
- 数据去向：video.id 关联到 ads.video_id、leads.video_id、reviews.video_ids

### 5. 投流板块
- 输入：videos 表
- 处理：千川投流 -> 数据回填（消耗/点击/成交）-> 效果监控
- 输出：ads 表（video_id/cost/views/cart_clicks/orders/revenue/roi/abnormal_flag）
- 责任人：投流专员（赵六）
- 状态：投放中 -> 已暂停 -> 已结束
- 异常分支：ROI<1 -> 停投重做；零投流 -> 标记自然流量，不参与ROI排名
- 数据去向：ads.video_id 是复盘分析的核心数据源

### 6. 客服私域板块
- 输入：视频评论/私信
- 处理：话术回复 -> 加微信 -> 成交跟进
- 输出：leads 表（id/video_id/question/intent/status/wechat_status）
- 责任人：客服专员（周七）
- 状态：待回复 -> 已跟进 -> 已加微 -> 已成交
- 异常分支：用户意向高但未成交 -> 设置下次跟进时间；加微失败 -> 转人工跟进
- 数据去向：leads.video_id 归因到具体视频

### 7. 数据复盘板块
- 输入：ads + videos + leads 数据
- 处理：计算ROI/CTR/完播率 -> 问题归因 -> 输出优化建议
- 输出：reviews 表（id/best_video/worst_video/overall_roi/problem/action）
- 责任人：运营主管（李四）
- 状态：待复盘 -> 复盘完成
- 异常分支：样本量过小（如自然流量）-> 单独标注，不做强结论
- 数据去向：复盘结果回写知识库，指导下一轮选品/内容

### 8. 知识库沉淀板块
- 输入：各环节经验 + 复盘结论
- 处理：分类整理 -> 写入完整提示词（knowledge/prompts.json）-> 供工作流/智能体加载
- 输出：knowledge_base 表 + prompts.json
- 责任人：全员
- 状态：草稿 -> 已发布 -> 已失效
- 异常分支：提示词效果差（AI输出不稳定）-> 降级回滚到上一版本

## 数据闭环（字段级）

products.id
  -> contents.product_id
  -> scripts.content_id / scripts.product_id
  -> videos.script_id
  -> ads.video_id / leads.video_id / reviews.video_ids
  -> knowledge_base（提示词沉淀）
  -> 反哺下一轮选品

## 优先用表格提效的环节
- 商品库、内容拆解、脚本分镜、视频生产：先用数据表管理状态和字段
